# OOPG adult-equivalent capacity-to-pay module

This module follows the WHO/Xu capacity-to-pay logic for OOPG only.

Adult equivalence uses the project scale: E = (A + 0.5K)^0.75.

Weighted food-share cut points: p45 =  0.482132, p55 =  0.526164.
Monthly subsistence line per adult equivalent:    8014.2584 NPR.

Reported CTP thresholds: 10%, 25%, and 40%.

The OOPG numerator remains household-level. Adult equivalence enters through the subsistence requirement and capacity-to-pay denominator.
